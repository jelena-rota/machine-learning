## Machine Learning Project
<br><br/>
**Data**

The house prices dataset was assembled and published by Dean De Cock. It is a set of 2'930 observations with 82 attributes each.

Training dataset (first 2'430 observations) was used to fit and evaluate 3 different models: simple, intermediate and complex model. Models were later used to predict house prices in the test dataset (last 500 observations).
<br><br/>

**Tasks**

The tasks carried out in the project are divided into 8 sections:

- An overview of the dataset
- Data cleaning
- Exploratory data analysis
- Feature engineering
- Feature encoding
- Baseline
- Models (simple, intermediate and complex model)
- Predicting on test data
